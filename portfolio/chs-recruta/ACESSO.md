# CHS Recruta Portátil — acesso e demonstração

Esta é uma **edição sanitizada de portfólio**, preparada para permitir que recrutadores naveguem pelo sistema sem expor dados reais da base utilizada no projeto original.

## Acessar a demo online

**[▶ Abrir o CHS Recruta no navegador](https://htmlpreview.github.io/?https://github.com/berger33/berger33/blob/main/portfolio/chs-recruta/app/CHS-Recruta-Demo.html)**

### Credenciais de demonstração

| Campo | Valor |
| --- | --- |
| Usuário | `demo` |
| Senha | `demo123` |
| Perfil | Administradora |

Após entrar, é possível navegar por dashboard, banco de talentos, vagas, triagem, financeiro, relatórios, auditoria, usuários, configurações, perfil e personalização visual.

## Baixar a versão portátil

**[⬇ Baixar CHS Recruta Portátil em um único arquivo HTML](https://htmlpreview.github.io/?https://github.com/berger33/berger33/blob/main/portfolio/chs-recruta/app/download.html)**

O botão acima gera automaticamente o arquivo:

`CHS-Recruta-Portatil-Demo.html`

Depois do download:

1. abra o arquivo em Chrome, Edge ou Firefox;
2. entre com `demo` / `demo123`;
3. navegue normalmente — nenhum servidor, banco externo ou instalação é necessária.

Os dados cadastrados durante a demonstração ficam armazenados localmente no navegador do próprio computador.

## Privacidade

A versão operacional original foi criada para uma necessidade real de RH e continha dados de terceiros. A edição pública substitui essa base por dados fictícios e mantém apenas as funcionalidades necessárias para demonstrar o produto.
